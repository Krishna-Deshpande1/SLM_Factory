# Cost of the ten main suite runs

GPU time and money for the SLM Factory's ten main runs (the suite in `SLMF.tex` and the 09-16 note, Part I). Generated by `scripts/cost_md.py`.

## In aggregate

| | Total for the 10 runs |
|---|--:|
| Wall clock | 305 h (12.7 days of single-job time) |
| GPU time | **611 L40S GPU-hours** (2 GPUs per job) |
| GPU time, rented-equivalent | **$604** at $0.99/GPU-h ($287–$2,137 across $0.47–$3.50/GPU-h) |
| Orchestrator API (Claude Sonnet 5) | $52.90 (857 calls) |
| Synthesis API (DeepSeek v4 Flash, xlam_bfcl only) | $38.05 |
| **Total, rented-equivalent** | **$695**, of which 87% is GPU time |
| Actually paid | **$90.95** in API fees: the GPUs are the university's Hyak cluster |
| Train + eval iterations | 813 |
| Local teacher / judge / inference calls (free) | 181,991 (9 runs) |

Not included: the zero-shot API baselines ($9.67 for all 20 Claude/DeepSeek cells), ablations, probes and the reruns they replaced.

## What drives the cost

- **GPU time is 87% of the rented-equivalent bill.** The orchestrator costs $1.89–$7.73 a run; GPU time costs $17–$134.
- **Two tasks are 44% of all GPU time:** clinc150 (135 GPU-h) and topv2 (134 GPU-h). Both climb all five tiers over 100+ iterations, and both are slow per iteration: clinc150's prompt lists all 151 intents (~1,385 tokens), and topv2 generates nested bracketed parses.
- **Cost per iteration, not iteration count, separates the tasks.** Iterations range 41–109, but wall-clock minutes per iteration range 7–39: short single-label or span answers (sms_spam, ner_bc5cdr) are cheap; long prompts and structured outputs (dialogsum, xlam_bfcl, topv2, clinc150) are not.
- **The runs that stop early are cheapest.** ner_bc5cdr and calendar_json converged at tier 3 in about nine hours each.
- **The one paid API teacher outspent every orchestrator.** xlam_bfcl's $38.05 of DeepSeek synthesis (52.7M output tokens, because the thinking-disable flag was only sent on the local path) is more than the other nine runs' orchestration combined, and 7.9× its own.

**Per-tier GPU-hours and dollars are not in this document yet.** They are only in each run's own files on Hyak: the per-iteration timeline in `logs/runs/<run>/checkpoint.json`, the API ledger (`cost.json` and the cost-event JSONL, one timestamped event per call) and the SLURM accounting. The notes record only per-run totals. Once those files are copied here, `scripts/cost_md.py --tiers` adds a per-tier table and figure.

## Method

- **GPU-hours** = SLURM wall clock × 2: every suite job holds two L40S GPUs (training and the local Qwen3.6-35B-A3B teacher, judge and generator) for its whole run.
- **Wall clock and iterations** come from the 09-16 note (Part IV.3), which measured them from the run logs; clinc150's 67.6 h covers its no-convergence rerun and its resume.
- **API dollars** are the per-run `cost:` summary lines (SLMF.tex, cost table), priced by `agent/cost.py` at public list rates.
- **GPU dollars are an estimate:** the runs used the university's Hyak cluster, which bills no per-hour rate. $0.99 per L40S GPU-hour is RunPod's US on-demand price in Hostinger's September 2026 comparison; specialist clouds range from $0.47 (Vast.ai) to about $1, and bare-metal or hyperscaler nodes cost several times more.

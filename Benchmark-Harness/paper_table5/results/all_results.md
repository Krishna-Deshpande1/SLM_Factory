Generated by `results/graphs/make_table.py` from `results/slm_pool_<phone>_{pinned,head}/configs/*.json`.

## Setup (same on every phone)

- 256-token prompt (prefill) and 256-token decode, 4 llama.cpp threads, 3+ recorded repetitions; values are mean ± standard deviation across repetitions (tokens per second).
- **Build** `pinned` = the paper's llama.cpp `eadc418` / MNN `510ac8f` (Qwen3, SmolLM2, Gemma3). `head` = llama.cpp `9c2e0e4` / MNN `a8ec497` (Qwen3.5 only; its architecture needs a newer build).
- **Precision** columns use each engine's own label: llama.cpp Q4_0 / Q8_0 / F16, MNN 4 / 8 / 16-bit (shown as Q4 / Q8 / F16).
- **Size (GiB)** is the on-disk weight size of the model file(s) pushed to the phone. The RAM guard refuses a run when estimated resident weights exceed 55% of the phone's RAM (MNN F16 is estimated at about 2x its file size).
- **Peak memory (MiB)** is the largest total memory of the inference process during one run of the same workload (256-token prompt, 256 generated tokens): PSS from `dumpsys meminfo` plus the GPU buffers that PSS does not show, sampled every 0.5 s by `memory_usage.py`; **GPU (MiB)** is the GPU part of it. **Measured on the OnePlus 15 only; — on the other phones means not measured.** On the OnePlus 15 `dumpsys meminfo` reports almost no GPU memory, so the GPU part is the rise of the system-wide `GPUTotalUsed` counter (`/proc/meminfo`) above its pre-run baseline (a patch to `memory_usage.py`). † = the benchmark segfaulted after completing the workload (MNN F16 on the GPU), so the peak is still the workload's. ‡ = repeat measurement used: the first reading of Gemma3-270M MNN Q4 CPU was 442 MiB, the repeat 272 MiB with the same resident memory (PSS attribution noise on memory-mapped pages); a repeat of 24 cells otherwise agreed within 10% (median 0.4%). Peak memory can exceed the phone's RAM because PSS also counts memory-mapped weight pages that are copied into GPU memory; the drop in the phone's free memory is saved in the raw records.
- **Energy (mJ/token)** is whole-device battery energy net of idle, measured through Perfetto (OnePlus 15) or sysfs battery current (Redmi 9A). — means not measured or not valid. **The OnePlus 8 Pro has no energy data at all** (Perfetto v25 on Android 13 cannot read its battery counters and sysfs battery files are not readable without root). The paper's energy is SoC-only, so it is not directly comparable.
- **Status**: `ok` = measured. Anything else says why there is no number.
